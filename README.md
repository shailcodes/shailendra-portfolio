# Shailendra Portfolio 🚀

A modern, responsive, and interactive personal portfolio website built with React and Tailwind CSS.




## 🌐 Live Demo

[Click here to view the live website](https://shailendra-dev.netlify.app)

## 🛠️ Tech Stack
- **Frontend Framework:** React.js
- **Build Tool:** Vite
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion, AOS (Animate On Scroll)
- **Form Backend:** Web3Forms

## ✨ Features
- Fully responsive design (Mobile, Tablet, Desktop)
- Smooth scroll animations and interactive UI elements
- Modern glassmorphism and gradient effects
- Functional contact form with direct email integration
- Clean, modular, and optimized code structure
